About Sana

Sana is your AI assistant and study companion. She can chat in Hindi, Hinglish, and English, help you study, and help with work and coding.

Version 1.0.0

Her spoken voice is a generic female voice from your phone, when the device has one. It is not a celebrity or a specific person’s voice.

Image understanding needs a vision-capable model on the server. If the model cannot read a file, Sana says so instead of pretending.

Web answers are labeled. If search results are missing, Sana will not invent links or current facts.

Privacy

Chats are stored on this phone so they survive a restart, and on the Sana server you connect to so the current conversation keeps its context.

A new chat gets a new conversation id. Old context is not mixed into it.

Persistent memory is saved only when you ask Sana to remember something, or add it in Memory. You can view, edit, and clear it.

Sana does not store passwords, API keys, payment details, or other secrets as memories. Do not paste secrets into chat.

The AI provider receives your message text so it can reply. The API key never leaves the server and is never shown in the app.

Microphone audio is turned into text by your device’s speech service, which may use that service’s online recognition. This app sends the text, not a saved recording, to Sana’s server.

You can clear this chat, all chats, and memory at any time in Settings.
